## 驗收標準
> Evaluator 將按此標準逐項評分

### 功能完整性（25%）
- [ ] [功能 1] 正常運作
- [ ] [功能 2] 正常運作
- [ ] 邊界情況處理（空輸入、超長輸入、特殊字元）

### 付費流程（25%）
- [ ] 免費用戶碰到用量上限時顯示升級提示
- [ ] 點擊付費後能成功跳轉綠界
- [ ] 付費回調正確開通 Pro 會員
- [ ] 用 ECPay 測試環境驗證

### 用戶體驗（20%）
- [ ] 首頁 30 秒內理解產品價值
- [ ] 操作流程直觀，不需要說明
- [ ] 手機端可用
- [ ] 繁體中文顯示正確

### 程式碼品質（15%）
- [ ] 無 XSS / CSRF / SQL injection
- [ ] TypeScript 無 any 型別
- [ ] API 端點有 JWT 驗證
- [ ] 錯誤處理完善

### 差異化（15%）
- [ ] [與競品的具體差異點]
