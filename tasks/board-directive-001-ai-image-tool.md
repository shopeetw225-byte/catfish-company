# 董事會指令 #001：AI 生圖工具產品調研

## 指令

董事會決定公司產品方向為 **AI 生圖工具**，面向台灣市場。

CEO 小張收到此指令後，帶領 PM 小陳進行市場調研，在 **1 個 Sprint 週期內**提交 **2-3 個具體產品方案**給董事會選擇。

## 約束條件

1. **目標市場：台灣**（繁體中文、綠界支付，不考慮大陸）
2. **不做通用生圖工具** — 不與 Midjourney / DALL-E / Stable Diffusion 正面競爭
3. **必須有明確付費場景** — 用戶為什麼願意每月付 NT$149-299
4. **技術棧不變** — Cloudflare Workers + Hono + D1 + React，生圖部分可用第三方 API（Replicate / Cloudflare Workers AI / 其他）
5. **62 個付費用戶是生死線** — 每個方案都必須回答「能不能在 6 個月內達到 62 個付費用戶」
6. **每用戶生圖 API 成本必須可控** — 生圖 API 單次成本通常 $0.01-0.10，需要建模到毛利率中

## 調研要求

每個方案必須使用 `docs/business-model.md` 中的「產品提案評估模板」完整填寫，並額外回答：

1. **生圖 API 選型** — 用哪個模型/服務？單次生成成本？
2. **免費版每日限額** — 幾張免費？如何設計付費牆讓人願意升級？
3. **差異化到底是什麼** — 台灣用戶為什麼不直接用 Canva AI / ChatGPT / 免費工具？
4. **獲客路徑** — 零預算情況下，怎麼讓台灣用戶知道這個工具？（SEO 關鍵字、PTT/Dcard、社群）
5. **競品定價對比** — 列出台灣市場現有生圖相關付費工具的定價

## 產品方向提示（僅供參考，不限於此）

董事會看到幾個可能的切入點，但不指定具體方向，由 CEO + PM 調研後判斷：

- **電商生圖** — 台灣蝦皮/PChome 賣家需要大量商品圖，背景移除/替換/情境圖
- **社群行銷圖** — 台灣中小企業需要 IG/FB 貼文圖、限時動態模板
- **個人化圖像** — 大頭照/證件照/節慶賀卡等有明確付費意願的場景
- **設計師輔助** — 台灣設計從業者的特定工作流（概念圖、mockup 生成）
- **其他你們調研後發現的機會**

## 交付物

1. **2-3 份完整產品提案**（使用評估模板）
2. **競品分析報告**（台灣市場 AI 生圖相關工具）
3. **CEO 推薦排序 + 理由**

交付到：`tasks/board-directive-001-proposals/` 目錄下

## 決策流程

```
CEO 收到指令 → CEO 指派 PM 調研 → PM 產出方案初稿
→ CEO 審查 + 補充商業判斷 → 提交董事會 → 董事會選定方案
→ 進入正式 Sprint 流程（PRD → Contract → Build → Evaluate）
```

## 注意事項

- 這是調研階段，**不要開始寫 code**
- 不需要走完整 Sprint 流程，但需要使用 `docs/agent-communication-protocol.md` 的通訊協議
- 調研結果如果發現「AI 生圖工具」方向不可行，**必須誠實說明並提出替代方向**
- 失敗案例教訓：不要重蹈 AI Tools 的覆轍（跟免費大廠正面競爭 = 死）
