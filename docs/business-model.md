# 商業模式與收入評估

## 公司定位

貓魚印象有限公司開發**簡單、能賺錢的付費軟件工具**，面向台灣和大陸市場。

不做：
- 開源項目
- 技術 demo
- 跟免費大廠產品直接競爭的東西

## 收入模式：SaaS 訂閱制

```
免費試用（7 天）→ 碰到用量上限 → 付費頁面 → 綠界結帳 → 開通會員 → 持續使用
```

### 定價策略

| 方案 | 價格 | 功能 |
|---|---|---|
| 免費版 | NT$0 | 每天 N 次使用，基本功能 |
| Pro 月付 | NT$149-299/月 | 無限使用，進階功能 |
| Pro 年付 | NT$1,490-2,990/年 | 月付價 × 10（省 2 個月） |

### 付費轉換漏斗

```
訪客 → 註冊（免費）→ 使用產品 → 碰到免費上限 → 看到付費頁面 → 付費
  100%    30%          80%          50%             30%           10%

目標：1000 訪客 → 300 註冊 → 9 付費用戶 ≈ 3% 轉換率
每月收入 = 9 × NT$199 ≈ NT$1,791
```

## 成本結構

### Cloudflare 成本（免費額度很大）

| 服務 | 免費額度 | 超出價格 |
|---|---|---|
| Workers | 10 萬次/天 | $0.30/百萬次 |
| D1 | 5GB 儲存 + 500 萬次讀 | $0.75/百萬次讀 |
| KV | 10 萬次/天 | $0.50/百萬次 |
| Workers AI | 按 token 計 | 模型依賴 |
| Pages | 無限靜態 | 免費 |

### AI API 成本（Workers AI / 第三方）

| 操作 | 預估成本 |
|---|---|
| Claude Haiku 短對話 | ~$0.001/次 |
| Workers AI Llama | 免費額度內 |
| 每用戶每月平均 | ~$0.50-2.00 |

### 毛利估算

```
月費收入: NT$199
AI API 成本: ~NT$15-60 (按 $0.50-2.00 USD)
Cloudflare 成本: ~NT$0 (免費額度內)
綠界手續費: ~NT$5 (2.75%)
───────────────────
毛利: NT$134-179 (67%-90%)
```

## 競爭優勢

1. **綠界支付** — 台灣最普及的第三方支付，支援信用卡/ATM/超商
2. **Cloudflare 全棧** — 全球 CDN 低延遲，成本極低
3. **AI Agent 團隊** — 開發速度快，人力成本低
4. **雙語市場** — 同一產品同時服務台灣和大陸

## 失敗案例教訓

### AI Tools 聊天工具（已砍）

**失敗原因：**
- AI 聊天市場飽和（ChatGPT/Claude/Gemini 免費就能用）
- 語法校正有 Grammarly
- 沒有差異化
- 上線後 0 個真實用戶

**教訓：**
- 不要跟免費大廠產品直接競爭
- 要找到用戶真正的痛點，不是「我們能做什麼 AI」
- 上線速度比功能完整更重要
