# 商業模式與收入評估

## 公司定位

貓魚印象有限公司開發**簡單、能賺錢的付費軟件工具**，面向台灣和大陸市場。

不做：
- 開源項目
- 技術 demo
- 跟免費大廠產品直接競爭的東西

## 收入模式：SaaS 訂閱制

```
免費試用（7 天）→ 碰到用量上限 → 付費頁面 → 綠界結帳 → 開通會員 → 持續使用
```

### 定價策略

| 方案 | 價格 | 功能 |
|---|---|---|
| 免費版 | NT$0 | 每天 N 次使用，基本功能 |
| Pro 月付 | NT$149-299/月 | 無限使用，進階功能 |
| Pro 年付 | NT$1,490-2,990/年 | 月付價 × 10（省 2 個月） |

### 付費轉換漏斗

```
訪客 → 註冊（免費）→ 使用產品 → 碰到免費上限 → 看到付費頁面 → 付費
  100%    30%          80%          50%             30%           5%

保守估計：1000 訪客 → 300 註冊 → 4-5 付費用戶 ≈ 1.5% 轉換率（新產品保守建模）
樂觀估計：3% 轉換率 = 9 付費用戶
```

## 完整成本結構

### 一、Agent 運營成本（主要成本 — 審查報告指出的致命缺陷）

> 之前的商業模型完全遺漏了 Agent 運營成本。這是最大的支出項。

| 項目 | 單價 | 頻率 | 月成本估算 |
|---|---|---|---|
| CEO heartbeat（5 min 間隔） | ~$0.02/次 | 8,640 次/月 | ~$170 |
| CTO/PM/QA heartbeat | ~$0.01/次 | 各 2,880 次/月 | ~$86 |
| 工程師 Sprint 工作（長時間 session） | ~$50-200/次 | 2-4 次/月 | ~$200-800 |
| QA 評估（Playwright + 測試） | ~$20-50/次 | 2-4 次/月 | ~$80-200 |
| **Agent 總月成本** | | | **~$536-1,256** |

換算台幣：**NT$16,000-38,000/月**

### 成本優化策略

1. **降低 heartbeat 頻率** — CEO 改 30 min，其他改 1 hr
2. **按需喚醒** — 只在有新任務時觸發，不靠定時器
3. **用更便宜的模型** — heartbeat 巡檢用 Haiku，只有 Sprint 用 Sonnet/Opus
4. **限制 Sprint 次數** — 每月最多 2 個完整 Sprint

### 優化後 Agent 成本估算

| 項目 | 優化後月成本 |
|---|---|
| CEO heartbeat（30 min，Haiku） | ~$30 |
| 其他 Agent heartbeat（1 hr，Haiku） | ~$20 |
| Sprint 工作（2 次/月，Sonnet） | ~$250 |
| QA 評估（2 次/月） | ~$60 |
| **優化後總月成本** | **~$360（≈ NT$11,000）** |

### 二、Cloudflare 成本

| 服務 | 免費額度 | 超出價格 |
|---|---|---|
| Workers | 10 萬次/天 | $0.30/百萬次 |
| D1 | 5GB + 500 萬次讀 | $0.75/百萬次讀 |
| KV | 10 萬次/天 | $0.50/百萬次 |
| Workers AI | 按 token | 模型依賴 |
| Pages | 無限靜態 | 免費 |

初期在免費額度內：**$0/月**

### 三、每用戶 AI API 成本

| 操作 | 預估成本 |
|---|---|
| Workers AI Llama（免費額度內） | $0 |
| Claude Haiku API（超出額度後） | ~$0.001/次 |
| 每用戶每月平均 | ~$0.50-2.00 |

### 四、損益平衡分析

```
固定成本（Agent 運營，優化後）：NT$11,000/月
每用戶變動成本：~NT$20/月（API + 綠界手續費）
每用戶收入：NT$199/月

每用戶貢獻利潤 = NT$199 - NT$20 = NT$179
損益平衡用戶數 = NT$11,000 ÷ NT$179 ≈ 62 個付費用戶

以 1.5% 轉換率計算：
需要月訪客 = 62 ÷ 0.015 ÷ 0.30（註冊率）≈ 13,778 訪客/月
```

### 五、獲客成本（CAC）模型

| 管道 | 預估 CAC | 說明 |
|---|---|---|
| SEO（自然搜尋） | NT$0 | 長期投入，3-6 個月見效 |
| Facebook/IG 廣告 | NT$50-150/用戶 | 台灣市場 CPC ~NT$5-15 |
| PTT/Dcard 社群 | NT$0 | 需要時間經營 |
| 口碑/推薦 | NT$0 | 最佳管道但需要好產品 |

初期策略：**零預算獲客**（SEO + 社群 + 產品口碑），不燒廣告。

## 競爭優勢

1. **綠界支付** — 台灣最普及的第三方支付
2. **Cloudflare 全棧** — 成本極低
3. **AI Agent 團隊** — 開發速度快（但要控制 Agent 成本）
4. **雙語市場** — 台灣先行，大陸後續

## 中國大陸市場評估

> 審查報告指出：大陸市場「零規劃」。正式回應：**M1 階段移除大陸市場，專注台灣。**

大陸市場暫不進入，原因：
- 需要 ICP 備案
- 需要微信/支付寶整合
- 合規要求複雜
- 分散初期精力

**決策：大陸市場從路線圖中移除，只在台灣市場驗證成功後再評估。**

## 失敗案例教訓

### AI Tools 聊天工具（已砍）

**失敗原因：**
- AI 聊天市場飽和
- 沒有差異化
- 上線後 0 個真實用戶
- Agent 成本遠超收入

**教訓：**
- 不要跟免費大廠產品直接競爭
- 先算清楚 Agent 成本再決定做什麼
- 62 個付費用戶是生死線
